# 本地 / 线上环境切换说明

> 目标：同一套自动化代码，只通过环境变量切换本地与线上；**不修改线上服务器代码/配置/数据库**。
> 线上环境默认禁止写业务数据，必须显式授权后才允许执行创建申请/审批等写操作。

## 1. 切换方式

```powershell
# 本地（默认，不设置变量即可）
$env:HP_ENV = "local"
Remove-Item Env:HP_BASE_URL -ErrorAction SilentlyContinue
$env:HP_BASE_URL  # 空 → 默认 http://127.0.0.1（可显式设为 http://127.0.0.1）

# 线上
$env:HP_ENV = "online"
$env:HP_BASE_URL = "http://172.16.29.215"
```

环境判定规则（`core/config.py`）：

- `HP_ENV=online` 或 `HP_BASE_URL` 非 127.0.0.1/localhost → 视为线上；
- 线上只读自检：`python scripts/env_check.py`（自动走 online 分支：入口/登录/关键接口/OnlyOffice，不碰 Docker/本地 MQ）；
- 本地自检仍为全栈检查（Docker/服务/账号/MQ 桥接）。

## 2. 安全闸门（重要）

| 能力 | 本地 | 线上 |
|---|---|---|
| 创建业务数据（全链 CLI） | 允许 | **默认拒绝**；需 `HP_ALLOW_ONLINE_WRITES=1` |
| pytest flows 业务用例 | 允许 | **默认 skip**；需 `HP_ALLOW_ONLINE_WRITES=1` |
| 本地 MQ 桥接 / Redis key 同步 | 自动启用 | 禁止（线上真实 relay/Redis） |
| 伪造 OnlyOffice JWT 回调保存报告 | 仅本地 | **禁止**；线上走 OnlyOffice 编辑器真实保存 |
| 测试数据清理脚本（改库） | 允许 | **禁止**；线上需走业务作废流程 |

线上执行全链需要显式授权：

```powershell
$env:HP_ENV='online'; $env:HP_BASE_URL='http://172.16.29.215'
$env:HP_ALLOW_ONLINE_WRITES='1'   # 仅在你确认允许创建线上测试数据后设置
python scripts/run_full_chain.py
```

> 注意：全链会真实创建采购申请、审批、审计、执行申请，并通知真实审批人。
> 建议使用专用测试账号 + 统一 `UI自动化-` 前缀，并事先确认线上测试数据的作废/清理方式。

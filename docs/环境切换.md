# 本地 / 线上环境切换说明

> 目标：同一套自动化代码，只通过环境变量切换本地与线上；**不修改线上服务器代码/配置/数据库**。
> 线上环境默认禁止写业务数据，必须显式授权后才允许执行创建申请/审批等写操作。

## 1. 切换方式

```powershell
# 本地（默认，不设置变量即可）
$env:HP_ENV = "local"
Remove-Item Env:HP_BASE_URL -ErrorAction SilentlyContinue
$env:HP_BASE_URL  # 空 → 默认 http://127.0.0.1（可显式设为 http://127.0.0.1）

# 线上
$env:HP_ENV = "online"
$env:HP_BASE_URL = "http://172.16.29.215"
```

环境判定规则（`core/config.py`）：

- `HP_ENV=online` 或 `HP_BASE_URL` 非 127.0.0.1/localhost → 视为线上；
- 线上只读自检：`python scripts/env_check.py`（自动走 online 分支：入口/登录/关键接口/OnlyOffice，不碰 Docker/本地 MQ）；
- 本地自检仍为全栈检查（Docker/服务/账号/MQ 桥接）。

## 2. 安全闸门（重要）

| 能力 | 本地 | 线上 |
|---|---|---|
| 创建业务数据（全链 CLI） | 允许 | **默认拒绝**；需 `HP_ALLOW_ONLINE_WRITES=1` |
| pytest flows 业务用例 | 允许 | **默认 skip**；需 `HP_ALLOW_ONLINE_WRITES=1` |
| 本地 MQ 桥接 / Redis key 同步 | 自动启用 | 禁止（线上真实 relay/Redis） |
| 伪造 OnlyOffice JWT 回调保存报告 | 仅本地 | **禁止**；线上走 OnlyOffice 编辑器真实保存 |
| 测试数据清理脚本（改库） | 允许 | **禁止**；线上需走业务作废流程 |

线上执行全链需要显式授权：

```powershell
$env:HP_ENV='online'; $env:HP_BASE_URL='http://172.16.29.215'
$env:HP_ALLOW_ONLINE_WRITES='1'   # 仅在你确认允许创建线上测试数据后设置
python scripts/run_full_chain.py
```

> 注意：全链会真实创建采购申请、审批、审计、执行申请，并通知真实审批人。
> 建议使用专用测试账号 + 统一 `UI自动化-` 前缀，并事先确认线上测试数据的作废/清理方式。

## 9. UI / 接口执行方式开关（2026-11-28 ~ 11-29）

除 S15（需求书编制）、S16（审计）仍为接口直调外，前置流程各步骤默认都走 **UI 操作**（接口只用于
定位数据与状态回读/断言）。线上旧前端未升级时可整体切回接口路径。

| 环境变量 | 取值 | 覆盖范围 |
|---|---|---|
| `HP_STEP_MODE` | `ui`（默认）/ `api` | 全局：S04 / 审批 / S18 / S19 / S20 |
| `HP_S04_MODE` | `ui` / `api` | 纪检分配监督员（监察项目列表 → 分配监督员弹窗） |
| `HP_APPROVAL_MODE` | `ui` / `api` | 所有审批节点（BT14 / BT6 / BT13）：采购工作台 → 待办 → 办理 → 通过 → 提交；BT6 采购办节点选评标方式，BT13 采购办节点选执行经办人 |
| `HP_S18_MODE` | `ui` / `api` | 采购需求审查：干事发起 → 各审查人【审查】→ 一键通过 → 保存 → 确认通过 |
| `HP_S19_MODE` | `ui` / `api` | 采购方式分配：行【分配方式】→ 选类别/方式/议比价方式/依据（唯一来源上传纪要）→ 推送主任审批 |
| `HP_S20_MODE` | `ui` / `api` | 采购执行申请：草稿行【提交审批】→ 确定 |
| `HP_EXTRACT_MODE` | `ui`（默认）/ `api` | S11 专家抽取：调研论证列表 → 规划页 → 勾选页 → 拨号登记页 |
| `HP_DIAL_MODE` | `MANUAL`（默认）/ `AUTO` | S11 规划页「通知方式」：手工拨号（登记参与，不依赖 mock 回调）/ 语音自动通知（走 professor mock 回调，线上 mock 已开启，本地需 MQ 桥接 + 结果绑定） |

- 优先级：`ctx[f"{step}_mode"]` > `HP_<STEP>_MODE` > `HP_STEP_MODE` > 默认 `ui`。
- 通知方式以**后端实际保存值**为准：规划后回读 `getDetail.dialMode`，旧版后端不识别该字段时仍为 `AUTO`，自动回落 mock 回调。
- 页面选择器依据 openresty `c29222ac`（2026-11-27）；Layui 单选/下拉均点渲染节点并校验原生控件值；
  表格固定列在表格不溢出时会被 Layui 隐藏，代码会自动改点主表行内按钮。

# 采购方式选择说明（S19）

当前 S19 支持在**自主采购（非政府采购）**下选择不同的采购方式，不再固定“比选采购”。

## 支持的方式（自主采购）

| 代码 | 名称 | 额外必填 |
|---|---|---|
| 1 | 委托采购 | — |
| 2 | 比选采购（默认） | 采购办主任评标方式（综合评分/最低评标价法） |
| 3 | 竞争谈判采购 | 采购办主任评标方式 |
| 4 | 唯一来源谈判采购 | 唯一性论证会议纪要附件 |
| 7 | 议（比）价采购 | 议比价方式：1 院内议价 / 2 院内比价 |

说明：零星采购(5)、紧急采购(6) 后端要求走各自专门页面，不在本流程支持；
政府采购方式需要政府采购买卖流程，当前流程默认自主采购，仅预留映射。

## 使用方式

### 1. 环境变量（最适合批量/固定配置）

```powershell
$env:HP_PURCHASE_METHOD='7'          # 1/2/3/4/7 或中文名称
$env:HP_IN_HOSPITAL_PRICE_TYPE='1'   # 方式=7 时：1 院内议价 / 2 院内比价
$env:HP_UNIQUENESS_ATTACHMENT='D:\path\唯一性论证会议纪要.pdf'  # 方式=4 时
$env:HP_BID_EVALUATION_FORM='1'      # 采购办主任评标方式：0 综合评分 / 1 最低评标价法
```

### 2. 单入口 CLI 参数

```powershell
python scripts/run_full_chain.py --purchase-method 7 --in-hospital-price-type 2
python scripts/run_full_chain.py --purchase-method 1
python scripts/run_full_chain.py --purchase-method 4 --uniqueness-attachment "D:\path\纪要.pdf"
```

### 3. 代码中指定（ctx）

```python
ctx["purchase_method"] = "7"
ctx["in_hospital_price_type"] = 1
```

## 校验规则（与后端一致）

- 采购类别 0=政府采购、1=自主采购，默认按申请单 `governmentProcurement` 自动判断；
- 政府采购不能用自主采购方式，反之亦然；
- 方式 7 必须选议比价方式（1/2）；
- 方式 4 必须上传唯一性论证会议纪要（文件名包含“唯一性论证会议纪要”）；
- 方式 2/3 在 BT6 采购办主任节点选择评标方式；
- 方式 1/4/7 不需要评标方式；
- 选择依据文本默认按方式生成，可用 `HP_PROCUREMENT_BASIS` 覆盖。

## 相关文件

- `core/procurement_method.py`：方式映射、参数校验、默认值
- `api/method_api.py`：提交采购方式（支持议比价方式/附件/评标方式）
- `flows/s19_method.py`：提交 + BT6 三节点（采购办主任按需选评标方式）
- `scripts/run_full_chain.py`：新增 `--purchase-method` 等参数

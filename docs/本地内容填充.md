# 本地内容填充说明（S15 需求书 / S16 审计报告）

## 背景

原实现只做 `createByTemplate` / `initReport` 后“保存”，生成的文档正文仍是模板示例内容
（例如需求书预算表里是“心电监护仪/8000/495900”），审计报告表体为空。

本地新增内容填充能力，把**项目、子包、预算、审计明细**写进 DOCX，再通过文件服务上传、
模拟 OnlyOffice `status=2` 回调替换文档当前版本（仅本地/测试环境）。

## 开关

```powershell
$env:HP_CONTENT_FILL='1'          # 打开内容填充
$env:HP_AUDIT_SAVE_MODE='callback'  # 审计报告用本地回调保存（配合内容填充）
```

默认关闭，不影响原有链路。

## 涉及文件

| 文件 | 作用 |
|---|---|
| `core/office_files.py` | 文件下载/上传、采购文档/审计报告 OnlyOffice 回调更新 |
| `core/doc_content.py` | `fill_requirement_document` / `fill_audit_report`（python-docx） |
| `flows/s15_requirement.py` | 创建需求书后按项目/子包/预算填充正文 |
| `flows/s16_audit.py` | 生成审计报告后按审计子包/明细填充表体 |

## 文件服务地址

- 默认本地：下载 `http://127.0.0.1:17707/doFile/download/?attachmentId=`，
  上传 `http://127.0.0.1:7807/doFile/upload`；
- 可通过 `HP_FILE_DOWNLOAD_BASE` / `HP_FILE_UPLOAD_URL` 覆盖；
- JWT secret 默认 `please-change-onlyoffice-jwt-secret`，可用 `HP_ONLYOFFICE_JWT_SECRET` 覆盖。

## 已验证（2026-11-19，本地）

```powershell
$env:HP_ARGUMENT_MQ_BRIDGE='1'; $env:HP_FULL_CHAIN='1'; $env:HP_CONTENT_FILL='1'
python -m pytest tests/flows/test_p2_requirement_audit.py -v -s
```

结果：**PASSED in 284.49s**，最终 status=20。抽查生成文件：

- 需求书（document_version=2）：
  - 采购项目名称 = 实际 runId
  - 项目概况 = 申请采购内容 + 申请理由
  - 采购预算表 = 实际子包号/子包名/预算金额（如 640000.00）
- 审计报告（reportVersion=2）：
  - 表体第 1 行 = 实际货物/服务名称、数量、单价、报审金额、使用科室、审核意见

## 限制

- 仅本地/测试环境可用（回调更新禁止在线上使用）；
- 需求书技术参数/商务要求表仍保留模板内容，只填充了项目名称/概况/预算表；
- 审计报告填充主表明细，其他固定说明段落保留模板内容；
- 模板结构变化时 `fill_*` 需要同步调整（当前按表头关键字定位）。

# 采购前置流程 UI 自动化 - 快速上手

> 适用：本地 Windows 开发机，目标系统为惠州中心人民医院电子化采购平台（采购交易系统 + 纪检监察平台）。
> 框架：Playwright + Pytest，全部测试数据使用 `UI自动化-*` 前缀。

## 1. 环境准备

1. 启动本地栈（另开窗口，首次启动会构建 Maven 工程，约 5~10 分钟）：

   ```powershell
   D:\Desktop\HuiZhouProject\start-local-project.cmd
   ```

2. 等待浏览器能打开 `http://127.0.0.1/HospitalProcurement/index.html`。
3. 检查环境：

   ```powershell
   cd D:\Desktop\HuiZhouAuto\automation_py
   $py = "C:\Users\Grayson\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
   & $py scripts/env_check.py
   ```

   期望：`PASS 40 / WARN 0 / FAIL 0`（OnlyOffice 与抽取 MQ 桥接在后续阶段需要）。

## 3. 跑测试

```powershell
cd D:\Desktop\HuiZhouAuto\automation_py
$py = "C:\Users\Grayson\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"

# 冒烟（页面/接口可用）
& $py -m pytest tests/smoke -q

# 默认回归（不跑长链，约 4 分钟）
& $py -m pytest -q

# 单条流程
& $py -m pytest tests/flows/test_p0_main.py -v -s

# 全链（P0→采购中，约 5 分钟，需先开启本地 MQ 桥接相关配置）
& $py -m pytest tests/flows/test_p3_procurement.py -v -s
```

开关：

| 环境变量 | 作用 |
|---|---|
| `HP_ARGUMENT_MQ_BRIDGE=1` | 允许跑专家抽取相关链（WP5/P2/P3） |
| `HP_FULL_CHAIN=1` | 允许跑 P2/P3 自包含全链 |
| `HP_APPROVAL_WRITE=1` | 允许跑有副作用的审批写测试 |

## 4. 单入口全链（推荐）

```powershell
cd D:\Desktop\HuiZhouAuto\automation_py
$py = "C:\Users\Grayson\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"

& $py scripts/run_full_chain.py                 # 全新全链（S01→S20，约 4~5 分钟）
& $py scripts/run_full_chain.py --headed        # 显示浏览器
& $py scripts/run_full_chain.py --resume        # 自动找最近未完成申请续跑
& $py scripts/run_full_chain.py --from S15      # 从指定步骤开始
& $py scripts/run_full_chain.py --retries 2     # 失败重试次数
```

- 成功条件：采购申请最终 `status=9 采购中`。
- 退出码：成功 `0`，失败 `1`。
- 报告：`reports/<runId>/report.json` + `report.html`（步骤/耗时/状态/错误/申请单号）。

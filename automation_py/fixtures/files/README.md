# 测试附件素材

本目录存放自动化流程中"必传附件"节点的统一素材。

| 文件 | 大小 | 用途 |
|---|---|---|
| `wjc测试文件.pdf` | 49,879 B | **默认上传文件**（优先 PDF） |
| `wjc测试文件.docx` | 10,221 B | 页面只接受 Word 时使用 |

## 使用规则

1. 默认优先上传 `wjc测试文件.pdf`；若页面/控件限制格式（仅 Word/Excel），改用 `.docx`。
2. 非必传节点不上传（采购申请附件、其他调研材料、公告附件、审计选填附件等）。
3. 单文件 ≤ 50MB、最多 10 个；不要上传无关文件。
4. 代码中通过相对路径读取本目录（`fixtures/files/wjc测试文件.pdf`），
   不要硬编码绝对路径；上传统一封装并断言"上传成功 + 附件列表出现文件名"。

## 各节点使用对照

| 节点 | 是否必传 | 文件 |
|---|---|---|
| 供应商调研响应文件（S08） | 必传 | `wjc测试文件.pdf`（仅收 Word 时 `.docx`） |
| 线下论证报告（S13） | 必传 | `wjc测试文件.pdf` |
| 采购执行 4 类固定文书（S20） | 必传 | 逐类上传 `wjc测试文件.pdf` |
| 采购申请/调研材料/公告附件/审计附件 | 选填 | 不上传 |

> 备注：需求书、审计报告由模板/OnlyOffice 生成，不走本目录手工上传。
